# BuildMe 药物化学实验工作流

从用户当前正在做的研究对象与实验进展启动。沿用已有目标分子、反应、课题假设和数据；已有课题时不要求重新选题。用户只需要某个步骤时直接处理该步骤。

## 使用课题事实

区分已知信息、用户提供的观察、待验证假设和缺少的信息。明确研究对象是结构、合成反应、分析方法还是活性实验。缺少目标结构、原始数据或设备能力时补齐影响当前任务的最少信息，不编造这些信息。

给出实验思路时说明它回答什么问题、变量与对照、独立实验单位、记录什么结果，以及哪些结果会挑战当前解释。独立反应／独立样品制备与同一样品重复进样或同一批次重复读数分别记录。保留失败、无效应和偏离计划的记录。

## 按当前任务选技能

- 结构读取、分子描述符、立体化学和结构图：`rdkit`。保留原结构，不自动去盐、改互变异构体、改变质子化状态或丢弃未指定手性；确实需要转换时记录转换策略。
- 候选系列的 CNS 规则和结构提醒：`medchem`。命中提醒需解释和对应实验检查，不能作为实测毒性或自动淘汰结论。
- 合成路线候选：`retrosynthesis`。只有本地 AiZynthFinder 环境、策略模型与库存就绪时才实际搜索；未配置时说明缺项，可继续整理用户已有路线与文献先例，不能伪造模型路线。
- 假设、替代解释和对照：`hypothesis-generation`；因素筛选、运行顺序、批次与响应面：`experimental-design`。依据实验资源和可行范围选设计，不默认统一重复次数。
- 校准响应、回收率、精密度和定量限：`analytical-method-validation`。确定研究用途和适用框架后采用事先明确的标准。
- 真实实验数据的比较、效应量、不确定性和诊断：`statistical-analysis`。分析对应配对、批次、独立样本和技术重复的层次。

这些技能已封装在本包中，按需求加载一个技能及其相关资源。上游文档中的额外服务、订阅、推广或非必要上传不属于本工作流。

## 实验与证据链

计划可以从 [实验计划资产](assets/experiment-plan.json) 建立；[反应及批次资产](assets/reaction-record.json) 给出与工作台 API 一致的记录草稿。资产中 `null` 表示尚无信息，不是默认实测值。

通过 `research_project` 读取当前课题和已存记录的 UUID，再用 `research_update` 保存草稿；不要虚构课题、化合物、方案或批次 ID。`savePlan` 必须有方案名称和已存在的 `targetCompoundId`；`recordRun` 必须关联已有 `planId` 和方案版本；`recordBatch` 必须有已有 `compoundId` 和批次号 `code`。资产中的必需空值填齐后才能调用工具。

实测记录和导入来源由科研工作台的记录者确认保存。助手可以整理录入草稿、分析已有数据和引用已有证据，但不能通过 `research_update` 将生成内容标成 `measured`／`imported`，也不能代替记录者确认实际实验完成或失败。反应草稿的运行状态可以是 `planned`，来源标签仍用 `proposed`。

给每个实际化合物和实验批次稳定编号，将结构、路线版本、实际执行条件、偏差、实际测量、原始文件与分析关联起来。至少能追溯“结论 → 分析／图表 → 实验批次 → 原始文件”。记录文件名和本地位置；真实文件可用时记录校验值，不伪造校验值或实验时间。

证据标签保持清楚：研究建议为 `proposed`，结构描述符为 `computed`，路线／模型结果为 `predicted`，文献信息为 `literature`，记录者声明的真实实验记录为 `measured`，原文件导入为 `imported`，演示资料为 `example`。这些标签可用 [证据资产](assets/evidence-ledger.json) 整理；论文结论和章节用 API 的 `evidenceIds` 关联实际已存证据 UUID。引用文献时核验实际来源及其与当前底物、体系和指标的适用性。

对阿尔兹海默症研究，分别描述目标机制、化合物身份／纯度、体系中的活性及适用的 CNS 性质证据；描述符、相似性、对接或 BBB 模型输出本身不能写成抗 AD 药效、实测入脑或临床效果。

## 按真实实验逐节写作

用户需要写作时，先读取对应批次、原始数据与分析。已执行且有记录的实验可写方法；尚未执行的内容保持为实验计划。结果部分只使用实测数据或已执行计算，并明确计算类型；讨论部分区分数据支持的结论、候选机制、替代解释和局限。

优先完成当前已有证据能支持的段落。证据缺口列为需要补测／补记录的事项，不补造产率、谱峰、统计量、活性、参考文献或失败实验。每段实质性结果绑定证据编号，用户可回查对应批次与数据。写作不要求结果显著，也不隐藏失败批次。
