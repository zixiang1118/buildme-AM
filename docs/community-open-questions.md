# 社区实现约定与待配置事项

更新：2026-10-05。基准：prd-community.md v1.1；本轮范围 C3–C8。

- GitHub OAuth、域名、下载地址、正式规则与联系方式暂缺，按 PRD 环境变量和占位方案继续；不需要真实凭据即可运行邀请码流程。
- C3已补齐楼层互动、表情、收藏和通知，普通表单仍支持关闭JavaScript使用。
- C6已补齐管理员/版主后台，首帖、举报和资料审核均可在后台处理。
- C4 起首页为热门，精华和搜索已开放；作品板块和作品墙已随 C5 启用。
- 原型的低对比辅助色仅用于装饰，正文辅助文字使用原型 --ink2；不改变原型 token 数值。Google Fonts 改为本地 woff2。
- 本机默认 Node 为 25；社区安装与验收使用单独下载的 Node 22 运行时，不修改全局 Node。根仓库继续使用其原有环境。
- C7 已接入桌面端真实成就与对比统计；网址可在桌面设置中填写，默认留空。GitHub真实授权待配置后人工验收。
- C0–C8功能与运维工具已交付；本地图片存储已验收，OSS实现尚未连接真实服务。GitHub 最短账号年龄默认 30 天，首帖审核默认开启。
- C4 用户主页采用用户名地址，保留旧数字 ID 链接跳转；列表快照分页有效期一小时，到期提示返回刷新。
- 本地预览使用显式 seed 内容；管理员需运行 `pnpm create-admin` 自行设置密码，再在管理页生成邀请码，没有内置演示密码。

- C8备份默认本地模式供演练；上线前需配置独立的私有OSS备份bucket并完成实际上传恢复验收。应用图片bucket与备份bucket用途不同。
- 性能结果来自本机Apple M1，匿名页面有10秒服务端缓存；部署主机容量与TLS耗时需要在实际环境测量。压测与安装验收环境分别记录，不能互相替代。
- 真实GitHub/OSS、正式域名与下载地址的配置后验收见 `community/deploy/manual-checks.md`；本轮不推送、不执行远程部署。
