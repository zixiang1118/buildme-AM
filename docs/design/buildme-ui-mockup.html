字体

BuildMe 搭出来

界面用 Schibsted Grotesk 加系统中文字体；所有数字、路径、命令用 JetBrains Mono 12.4k，数字等宽对齐。两套字体都随安装包内置，不联网加载。

规则

  • 颜色有含义：陶土色只给「你的 Agent」和主要操作，蓝色只给 X 光
  • 不用 emoji 当图标，统一 1.5px 线性图标
  • 层级靠 1px 描边和底色深浅区分，阴影只给弹出层
  • 圆角三档：控件 8，卡片 10，窗口 12
  • 浅色、深色两套主题同等完成度
