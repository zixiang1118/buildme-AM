# BuildMe：把 AI 的能力，变成你的能力

[中文首页](../README.md) · [English introduction](../README.en.md) · [产品介绍页](https://jsdnaasd.github.io/buildme-agent/)

BuildMe 是一个通用 Agent 工作台。它帮助人完成真实任务，也把执行过程变成可以观察、调整和比较的对象。

## 我们的理念

**Build to understand. Understand to build.**

创造与理解应该互相促进。完成一个作品时，你也能看见模型读了哪些文件、为什么需要工具、上下文如何增长，以及切换一种能力后执行路径发生了什么变化。这些判断会成为下一次创造的基础。

我们从用户自己的任务出发，让学习自然发生。学生、创作者、开发者和老师都可以带来自己的项目；产品不设置固定考试，也不按答案给人排名。

## 产品循环

1. **创造**：围绕本地项目提出真实需求，用 Agent 推进代码、资料和作品。
2. **看见**：展开 X 光，查看实际提示词、模型调用、工具结果、上下文和子任务。
3. **调整**：通过九项能力开关改变下一回合的工具、提示词和运行时行为。
4. **比较**：在连续双路聊天中，让不同引擎、模型或读取策略处理相同任务。
5. **分享**：把作品与发现整理成社区内容，让别人的实践也能成为新的起点。

## 核心特点

- **可观察**：X 光、Token 账单和发现卡围绕真实运行记录展开。缺失数据不补零，估算不冒充账单。
- **可调整**：基础能力始终可用，九项扩展由用户选择。能力依赖与子任务继承在运行时生效。
- **可比较**：Pi 与 DSH 使用独立会话和工作区副本；双路支持多轮追问、历史恢复和文件 diff。
- **可行动**：读取、写入、编辑和命令执行能够产生真实项目文件，用户可以检查并继续使用。
- **可选择**：用户自行连接模型服务或本地模型，自行决定额外讲解与对比的调用。
- **可扩展**：桌面、CLI、Agent 内核、插件、提示词和社区源码一起公开，基于 MIT 许可证协作。

## 我们如何表达产品事实

以代码和验收记录区分“已有”“需配置”和“未来设想”。同模型比较能提供观察依据，但不能排除生成随机性；模型没有提供的思考过程不会被补写。

聊天、Trace 和设置默认保存在本机。远程模型调用会把任务所需内容发送给所选提供商。社区是独立服务，需要配置和部署；它不会默认接收完整本地聊天记录。

双路默认自动执行、免工具审批，同时保留独立副本和只读边界。采用到原文件前仍需确认并检查冲突。

## 当前交付与下一步

当前代码包含两引擎、单路/双路聊天、X 光、九项能力、30 项确定性成就、深入讲解、模型/读取策略对比，以及独立社区服务。macOS arm64 有实测记录，Windows / Linux 桌面验证仍待完成。跨 worker 子任务采集与单次性能尾部波动等限制见验收文档。

开发重点是继续提高稳定性、降低第一次使用的理解成本、完善跨平台体验，并让每一次解释都能定位到真实事件。[功能构想](feature-ideas.md) 收录探索方向，不作为当前交付承诺。
