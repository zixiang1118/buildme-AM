# 历史固定科研方案（已停用）

此文档对应此前的药物化学工作台，已从默认界面、技能加载与运行入口撤下。现行科研版支持用户搭建自己的平台，请参阅 [科研平台搭建指南](platform-builder.md)。已有 `.buildme/research` 档案保留原状。

这版工作台面向阿尔兹海默症相关的小分子药物研究，从研究生已有的分子、反应和实验问题开始。主要流程是：**分子 → 合成方案 → 实际反应 → 产物批次 → 表征与活性 → 论文证据**。

## 在这台电脑上开始

双击桌面的 **BuildMe** 快捷方式，打开共用工作台。在左上角 BuildMe 的版本菜单中切换「原版」「学习版」「科研版」；三种版本都保留各自的欢迎页。「科研工作台」只在科研版的欢迎页和侧栏显示，实验工作台顶部同样可切换版本。

1. 在「课题总览」创建课题，填写当前研究问题和靶点／体系；不需要先选题或写综述。
2. 在「分子库」录入 SMILES，或导入 MOL、SDF、SMI 文件。点击「计算分子性质」查看真实 RDKit 结构图和描述符；点击逆合成搜索得到本地模型的候选路线。
3. 在「合成方案」记录反应思路、因素、对照和重复安排。修订保留历史版本，实际反应引用执行时的版本。
4. 在「实验记录」填写实际条件、偏差、收率和失败情况，并登记产物批次。将谱图、色谱和其他原始文件关联到反应／批次。
5. 在「表征与活性」登记检测方法、单位、对照与读数，或导入 CSV／TSV／XLSX，然后运行描述统计。
6. 在「论文与证据」按当前记录整理方法、结果和讨论草稿。点击证据标签回查实验、历史分析与原始文件。证据更新后，已有草稿会提示需要复核。

「实验思路」「讨论结构与路线」「条件优化」等按钮会将当前课题及相关技能组成的任务放入聊天输入框，检查后发送。AI 建议需要在「模型与偏好」配置你自己的模型连接；课题记录、数据导入、描述统计、分子计算和本地逆合成不需要调用聊天 API。

## 原始读数格式

CSV、TSV 和 Excel 首行使用下面这些列名；其中 `sampleId` 和 `value` 必填。

```csv
sampleId,concentration,value,replicate,group
sample-A,1,12.3,1,处理组
sample-A,1,12.8,2,处理组
sample-B,1,10.6,1,处理组
sample-C,1,,1,处理组
```

- 同一个实际样品的重复检测使用相同 `sampleId`；不同编号是否代表独立实验，需要研究者核对。
- 在每个组别和浓度内，先对同一样品的重复读数取平均，再计算样品数量、均值、中位数、样品标准差和范围。显示的读数数量与样品数量分别保留。
- 空读数保留为缺失值，不补为零。未检出／低于定量限的说明保留在原资料和检测备注中。
- 第一版内置分析是描述统计。配对分析、显著性检验、IC50 拟合等需要根据实际设计另行选择方法，不能从描述统计自动推出药效结论。
- XLSX 读取第一个非空工作表，要求纯数值单元格；公式／复杂单元格需先粘贴为值。旧 `.xls` 请先另存为 `.xlsx`。导入的原文件会独立归档。

## 已封装的技能

| 技能 | 用途 |
|---|---|
| buildme-medicinal-research | 实验、批次、分析与论文的工作流连接 |
| hypothesis-generation | 实验假设、竞争解释和验证思路 |
| rdkit | 结构读取、立体化学、分子描述符和结构图 |
| medchem | CNS 等性质规则、结构提醒和系列比较 |
| retrosynthesis | AiZynthFinder 候选合成路线搜索 |
| experimental-design | 条件筛选、对照、批次与重复设计 |
| analytical-method-validation | 表征／检测方法的质量控制 |
| statistical-analysis | 根据实验设计选择统计方法与诊断 |

七个上游技能固定到具体提交版本，保留脚本、参考资料和许可证；另有一个 BuildMe 工作流技能。来源及依赖见 `bundles/research/manifest.json`。两个 Agent 引擎都可发现并加载这些技能。

技能安装与某个分析脚本的依赖就绪是两件事：本机已配置 RDKit、medchem 和 AiZynthFinder；额外 DoE、绘图或统计依赖按任务核对后安装。上游技能中的可选云服务不构成工作台的必需步骤。

## 本机计算环境

运行配置位于 `%LOCALAPPDATA%\BuildMe\research-runtime\config.json`。基础化学与逆合成使用独立 Python 环境，以兼容不同 RDKit／NumPy 版本。

本机已配置 RDKit 2026.3.6、medchem 2.1.1，以及 AiZynthFinder 4.4.1。公开策略模型、反应模板和完整 ZINC 原料库存存放在 `D:\BuildMeResearchRuntime\models`，已核对发布方校验值；下载来源与许可证记录在 `D:\BuildMeResearchRuntime\models\data-provenance.json`。

候选路线搜索每次处理一个分子，最多 100 次搜索迭代、6 层转化，搜索预算 90 秒；载入完整库存和启动引擎还需要额外时间。工作台同一时间运行一项搜索。随机种子、模型／库存指纹、目标结构、实际配置和日志保存在运行档案，并复制关联到课题。库存命中和模型搜索结果均属于计算预测，不能当作实验成功。

在另一台 Windows 电脑安装基础环境可运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\scripts\setup-research-chemistry.ps1
```

需已有 Python 3.11／3.12。逆合成环境可通过该脚本的 `-WithRetrosynthesis` 安装；模型与库存使用 `bundles/research/download-public-retrosynthesis.py` 单独下载和校验，再以 `-RetrosynthesisConfig` 指定生成的本地配置。发布应用包含技能与辅助脚本，Python 环境和大型模型是本机外部依赖。

## 数据与结论的边界

工作台区分实测、导入、文献、计算、预测、示例与待验证建议。实测标签由使用者声明，不代表软件已核验科学真伪；导入表格也可能是示例，需如实标记对应批次。专用 `research_update` 工具不允许把助手生成的内容标为实测或覆盖已有实测记录。

计算描述符、CNS 规则与候选路线用于设计下一步实验，不能证明化合物入脑、安全、抗 AD 有效或能够实际合成。本版不控制实验仪器、不执行物理实验；反应条件与路线仍需结合具体底物、文献及实验室条件审查。

## 保存与导出

每个工作区的研究档案在 `.buildme/research/projects/<课题ID>/`。原始文件复制归档并记录 SHA-256；查看文件时复核指纹。检测记录更新会保留以前的原始数据版本。

点击「导出课题」选择父目录，生成独立的课题目录，包含 `manifest.json`、说明文件和原始附件。保留整个导出目录即可携带数据和证据关系；大型模型／库存通过运行档案中的来源与指纹追溯，不重复放入每个课题。
